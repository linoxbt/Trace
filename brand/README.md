# Trace brand

## The mark

A **T whose stem lands in a check**: the bar is the hold PayPal places, the check is the proof that releases it. It sits on a squircle tile in Trace violet.

| File | Use |
| --- | --- |
| `trace-mark.svg` | Default: violet tile, white glyph |
| `trace-mark-ink.svg` | One-colour, on light or busy backgrounds |
| `trace-mark-cream.svg` | On violet or dark photography |
| `trace-glyph.svg` | The glyph alone, for watermarks and stamps |
| `trace-lockup.svg`, `trace-lockup-dark.svg` | Mark plus wordmark |

Keep clear space of half the tile's width on every side. Smallest size: 16 px.

## Wordmark

`trace`, lowercase, Geist SemiBold, letter-spacing −0.05em. The lockup SVGs use live text; outline it in a design tool before print.

## Colour

| Token | Hex | Role |
| --- | --- | --- |
| Violet | `#5b2fd6` | Primary actions, links, the mark |
| Violet deep | `#4b22c4` | Gradients, pressed states |
| Lilac | `#c6b5ff` | Accents on dark |
| Violet soft | `#efe9ff` | Tints and selected states |
| Cream | `#f5f0e6` | Page background |
| Ink | `#1a1325` | Text and dark surfaces |
| Night | `#120c1c` | Dark sections |

Green, amber and red appear only as status (verified, needs review, failed), never as brand colour.

## Type

Instrument Serif for display headlines, Geist for everything else, Geist Mono for every amount, ID and timestamp.
