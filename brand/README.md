# Trace brand

## The mark

**Two bars**: the solid one is money released for proved work, the outlined one is money still held. Every Trace job is somewhere between the two, and moves from right to left as lines are proved. The outlined bar is inset by half its stroke, so both share the same outer edge. It sits on a squircle tile in Trace violet.

| File | Use |
| --- | --- |
| `trace-mark.svg` | Default: violet tile, white glyph |
| `trace-mark-ink.svg` | One-colour, on light or busy backgrounds |
| `trace-mark-cream.svg` | On violet or dark photography |
| `trace-glyph.svg` | The two bars alone, for watermarks and stamps |
| `trace-lockup.svg`, `trace-lockup-dark.svg` | Mark plus wordmark |

Keep clear space of half the tile's width on every side. Smallest size: 16 px.

## Wordmark

`trace`, lowercase, Outfit Bold, letter-spacing −0.06em. The lockup SVGs use live text; outline it in a design tool before print.

## Colour

| Token | Hex | Role |
| --- | --- | --- |

| Brass | `#b97f52` | The second dot: held money, warm accents |
| Paper | `#f0eff4` | Page background |
| Card | `#ffffff` | Clay cards, lifted with a soft wide shadow |
| Ink | `#16121d` | Text and dark buttons |
| Night | `#150f22` | Dark sections and the footer |

Green, amber and red appear only as status (verified, needs review, failed), never as brand colour.

## Type

Outfit Bold, set tight, for display headlines; Figtree for everything else; JetBrains Mono for every amount, ID, timestamp and section eyebrow. Accent words change colour and never slant.

## Motion

The brand's material is dots. The home hero is a field of about a thousand that settle into the job's four moments (held, proved, verified, released) and scatter between them; the same dots drift behind page heroes and make up the geofence map. Body statements light up word by word as they scroll past, cards rise on reveal, and Lenis smooths the scroll. Everything holds still under reduced motion.
